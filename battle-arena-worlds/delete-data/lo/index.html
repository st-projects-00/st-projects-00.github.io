Battle Arena Worlds ບໍ່ຕ້ອງລົງທະບຽນ. ຫຼັງຈາກທ່ານຍອມຮັບຂໍ້ກຳນົດການໃຫ້ບໍລິການ ແລະ ນະໂຍບາຍຄວາມເປັນສ່ວນຕົວແລ້ວ, ເກມຈະນຳທ່ານເຂົ້າສູ່ລະບົບ Epic Online Services ດ້ວຍບັນຊີຜູ້ຫຼິ້ນແບບບໍ່ລະບຸຕົວຕົນທີ່ຜູກກັບໂທລະສັບຂອງທ່ານ, ແລະ ກະເປົາເງິນຮ້ານຄ້າຂອງທ່ານ (ຫຼຽນ, ເພັດ ແລະ ຂອງຕົກແຕ່ງທີ່ທ່ານເປັນເຈົ້າຂອງ) ຖືກເກັບໄວ້ໃນເຊີບເວີຂອງພວກເຮົາພາຍໃຕ້ ID ຜູ້ຫຼິ້ນ ຂອງບັນຊີນັ້ນ. ຖ້າທ່ານເລືອກເຂົ້າສູ່ລະບົບດ້ວຍ Google, Epic ຍັງເຊື່ອມໂຍງບັນຊີ Google ຂອງທ່ານກັບ ID ຜູ້ຫຼິ້ນນັ້ນ. ໜ້ານີ້ອະທິບາຍວິທີໃຫ້ລຶບຂໍ້ມູນນັ້ນ.

ລຶບໃນເກມ (ແນະນຳ)

  1. ເປີດ Battle Arena Worlds ແລະ ເຊື່ອມຕໍ່ອິນເຕີເນັດ.
  2. ໄປທີ່ແຖບ ການຕັ້ງຄ່າ. ພາຍໃຕ້ ບັນຊີ, ແຕະ ລຶບຂໍ້ມູນຂອງຂ້ອຍ.
  3. ຢືນຢັນສອງຄັ້ງ. ຖ້າມີການຊື້ທີ່ຍັງຢູ່ໃນລະຫວ່າງການຢືນຢັນ, ເກມຈະເຕືອນທ່ານກ່ອນ.

ການລຶບເກີດຂຶ້ນທັນທີ. ຈາກນັ້ນເກມຈະເລີ່ມບັນຊີຜູ້ຫຼິ້ນໃໝ່ທີ່ຫວ່າງເປົ່າໃນໂທລະສັບຂອງທ່ານ. ຖ້າທ່ານໄດ້ຖອນການຕິດຕັ້ງເກມແລ້ວ ແຕ່ເຄີຍເຂົ້າສູ່ລະບົບດ້ວຍ Google, ທ່ານຍັງສາມາດເຮັດສິ່ງນີ້ໄດ້: ຕິດຕັ້ງມັນຄືນ, ເຂົ້າສູ່ລະບົບດ້ວຍບັນຊີ Google ດຽວກັນໃນການຕັ້ງຄ່າ, ແລ້ວແຕະ ລຶບຂໍ້ມູນຂອງຂ້ອຍ.

ຫຼື ຂໍໃຫ້ພວກເຮົາທາງອີເມວ

ຖ້າທ່ານບໍ່ສາມາດໃຊ້ເກມໄດ້, ສົ່ງອີເມວໄປທີ່ battlearenaunlimited@gmail.com ດ້ວຍຫົວຂໍ້ "Battle Arena Worlds data deletion" ແລະ ໃສ່ຢ່າງໃດຢ່າງໜຶ່ງ:

  • ລະຫັດຜູ້ຫຼິ້ນ ຂອງທ່ານ, ທີ່ສະແດງໃນເກມພາຍໃຕ້ ການຕັ້ງຄ່າ > ບັນຊີ (ແຕະມັນເພື່ອສຳເນົາ); ຫຼື
  • ເລກຄຳສັ່ງຊື້ (ເລີ່ມດ້ວຍ GPA.) ຈາກໃບຮັບເງິນ Google Play ຂອງການຊື້ເພັດ ຫຼື ແພັກເລີ່ມຕົ້ນໃດໜຶ່ງທີ່ທ່ານໄດ້ເຮັດໃນເກມ. ທ່ານສາມາດຊອກຫາມັນໄດ້ໃນອີເມວໃບຮັບເງິນຈາກ Google Play, ຫຼື ໃນແອັບ Play Store ພາຍໃຕ້ ການຈ່າຍເງິນ ແລະ ການສະໝັກໃຊ້ > ງົບປະມານ ແລະ ປະຫວັດ. ບັນທຶກການຊື້ຂອງພວກເຮົາເຊື່ອມໂຍງຄຳສັ່ງຊື້ນັ້ນກັບ ID ຜູ້ຫຼິ້ນຂອງທ່ານ, ນັ້ນຄືວິທີທີ່ພວກເຮົາຊອກຫາກະເປົາເງິນຂອງທ່ານ.

ພວກເຮົາຈະຕອບກັບພາຍໃນ 30 ວັນ, ແລະ ພວກເຮົາຈະຢືນຢັນເມື່ອຂໍ້ມູນຂອງທ່ານຖືກລຶບແລ້ວ. ເມື່ອພວກເຮົາລຶບທາງອີເມວ, ໂທລະສັບຂອງທ່ານຍັງຖື ID ຜູ້ຫຼິ້ນອັນເກົ່າ, ດັ່ງນັ້ນເກມຈະເປີດກະເປົາເງິນໃໝ່ທີ່ຫວ່າງເປົ່າພາຍໃຕ້ມັນໃນຄັ້ງຕໍ່ໄປທີ່ມັນເລີ່ມ. ເພື່ອຢຸດສິ່ງນັ້ນ, ໃຫ້ລຶບຂໍ້ມູນຂອງເກມ ຫຼື ຖອນການຕິດຕັ້ງມັນ, ກ່ອນ ຫຼື ຫຼັງຈາກທ່ານຂຽນຫາພວກເຮົາ.

ຖ້າທ່ານບໍ່ເຄີຍຊື້ຫຍັງ ແລະ ບໍ່ມີເກມແລ້ວ, ກະເປົາເງິນຂອງທ່ານຖືກບັນທຶກພາຍໃຕ້ ID ຜູ້ຫຼິ້ນແບບສຸ່ມເທົ່ານັ້ນ ໂດຍບໍ່ມີຊື່, ອີເມວ ຫຼື ລາຍລະອຽດການຕິດຕໍ່, ແລະ ພວກເຮົາບໍ່ມີທາງລະບຸມັນໄດ້.

ຂໍ້ມູນສິ່ງທີ່ເກີດຂຶ້ນ
ກະເປົາເງິນຂອງທ່ານ: ຫຼຽນ, ເພັດ, ຂອງຕົກແຕ່ງທີ່ເປັນເຈົ້າຂອງ ແລະ ທີ່ໃສ່ຢູ່, ສະຖານະແພັກເລີ່ມຕົ້ນ, ຍອດລວມຫຼຽນລາຍວັນ ແລະ ການໃຊ້ຈ່າຍລາຍເດືອນ, ເວລາທີ່ສ້າງ ແລະ ປ່ຽນແປງຄັ້ງສຸດທ້າຍຖືກລຶບອອກຈາກຖານຂໍ້ມູນທີ່ໃຊ້ງານຢູ່ຂອງພວກເຮົາທັນທີ
ເວີຊັນກ່ອນໜ້າຂອງກະເປົາເງິນຂອງທ່ານ (ສູງສຸດ 2)ຖືກລຶບອອກຈາກຖານຂໍ້ມູນທີ່ໃຊ້ງານຢູ່ຂອງພວກເຮົາທັນທີ
ບັນທຶກຂອງແມັດ ແລະ ການຊື້ທີ່ເຄຣດິດເຂົ້າກະເປົາເງິນຂອງທ່ານຖືກລຶບອອກຈາກຖານຂໍ້ມູນທີ່ໃຊ້ງານຢູ່ຂອງພວກເຮົາທັນທີ. ການຊື້ທີ່ໄດ້ເຄຣດິດແລ້ວບໍ່ສາມາດເຄຣດິດໃຫ້ບັນຊີອື່ນໄດ້ອີກ.
ID ຜູ້ຫຼິ້ນຂອງທ່ານໃນບັນທຶກການຊື້ຂອງທ່ານ, ແລະ ແທັກບັນຊີທີ່ Google Play ລາຍງານສຳລັບແຕ່ລະຄຳສັ່ງຊື້ຖືກເອົາອອກຈາກຖານຂໍ້ມູນທີ່ໃຊ້ງານຢູ່ຂອງພວກເຮົາທັນທີ
ເຊດຊັນຂອງທ່ານກັບເຊີບເວີຂອງພວກເຮົາຖືກສິ້ນສຸດ
ບັນທຶກການຊື້ ແລະ ຄຳສັ່ງຊື້ (ສິນຄ້າ, ເລກຄຳສັ່ງຊື້, ເວລາຊື້, ສະຖານະ, ລາຍລະອຽດການຄືນເງິນ)ເກັບໄວ້ 7 ປີຫຼັງຈາກການຊື້ ສຳລັບພາສີ, ການຄືນເງິນ ແລະ ການປ້ອງກັນການສໍ້ໂກງ, ໂດຍບໍ່ມີ ID ຜູ້ຫຼິ້ນຂອງທ່ານ, ຈາກນັ້ນຖືກລຶບອັດຕະໂນມັດໂດຍວຽກທຳຄວາມສະອາດປະຈຳວັນ, ພ້ອມກັບການແຈ້ງເຕືອນການຄືນເງິນ ແລະ ການຍົກເລີກຂອງພວກມັນ
ສຳເນົາຂອງຂໍ້ມູນຂ້າງເທິງໃນຂໍ້ມູນສຳຮອງຖານຂໍ້ມູນທີ່ເຂົ້າລະຫັດຂອງພວກເຮົາ (ປະຫວັດການກູ້ຄືນແບບຈຸດເວລາຂອງ 7 ມື້ລ່າສຸດ, ຂໍ້ມູນສຳຮອງລາຍວັນທີ່ເກັບໄວ້ 7 ມື້, ຂໍ້ມູນສຳຮອງລາຍອາທິດທີ່ເກັບໄວ້ 14 ອາທິດ)ການສຳຮອງຂໍ້ມູນບໍ່ສາມາດແກ້ໄຂໄດ້, ສະນັ້ນຂໍ້ມູນທີ່ຖືກລຶບຈະຍັງຄົງຢູ່ໃນພວກມັນຈົນກວ່າຈະໝົດອາຍຸ: ສູງສຸດ 14 ອາທິດ. ພວກເຮົາໃຊ້ພວກມັນພຽງເພື່ອກູ້ຄືນຈາກການສູນເສຍຂໍ້ມູນ ຫຼື ເພື່ອກູ້ຄືນກະເປົາເງິນຂອງຜູ້ຫຼິ້ນຕາມຄຳຂໍຂອງເຂົາເຈົ້າເທົ່ານັ້ນ, ບໍ່ເຄີຍໃຊ້ເພື່ອນຳກະເປົາເງິນທີ່ຖືກລຶບແລ້ວກັບຄືນມາ.
ບັນທຶກເຊີບເວີ (ເວລາ, ປະເພດ ແລະ ຜົນຂອງຄຳຮ້ອງຂໍ, ທີ່ຢູ່ IP, user agent ຂອງອຸປະກອນ, ແລະ ໃນບາງແຖວ 12 ຕົວອັກສອນທຳອິດຂອງ ID ຜູ້ຫຼິ້ນຂອງທ່ານ, ສິນຄ້າ, ເລກຄຳສັ່ງຊື້, ລາຍການທີ່ຊື້ ຫຼື ຫຼຽນທີ່ເຄຣດິດ)ຖືກລຶບອັດຕະໂນມັດໂດຍ Google Cloud ຫຼັງຈາກປະມານ 30 ວັນ (ຄ່າເລີ່ມຕົ້ນ)

ຫຼຽນ, ເພັດ ແລະ ຂອງຕົກແຕ່ງທີ່ຖືກລຶບ, ລວມທັງທີ່ຊື້ດ້ວຍເພັດ, ບໍ່ສາມາດກູ້ຄືນໄດ້. ຖ້າທ່ານຫຼິ້ນອີກ, ທ່ານຈະເລີ່ມດ້ວຍກະເປົາເງິນຫວ່າງເປົ່າ. Google Play ເກັບບັນທຶກການຈ່າຍເງິນຂອງທ່ານເອງ, ລວມທັງແທັກບັນຊີ (ຄ່າແຮຊແບບທາງດຽວຂອງ ID ຜູ້ຫຼິ້ນຂອງທ່ານ) ໃນແຕ່ລະຄຳສັ່ງຊື້, ແລະ ພວກເຮົາບໍ່ສາມາດເອົາພວກມັນອອກໄດ້.

ຂໍ້ມູນທີ່ Epic ຖືໄວ້

Epic Games, ເຊິ່ງໃຫ້ບໍລິການການເຂົ້າສູ່ລະບົບ ແລະ ແມັດອອນລາຍ, ຖືບັນທຶກສຳລັບ ID ຜູ້ຫຼິ້ນຂອງທ່ານ: ID ອຸປະກອນແບບບໍ່ລະບຸຕົວຕົນ, ຊື່ຜູ້ຫຼິ້ນທີ່ສ້າງຂຶ້ນ (ຕົວຢ່າງ Player4821), ຍີ່ຫໍ້ ແລະ ລຸ້ນໂທລະສັບຂອງທ່ານ, ແລະ, ຖ້າທ່ານເຂົ້າສູ່ລະບົບດ້ວຍ Google, ການເຊື່ອມໂຍງກັບບັນຊີ Google ຂອງທ່ານ. ການລຶບໃນເກມຍັງເອົາການເຊື່ອມໂຍງ Google ແລະ ID ອຸປະກອນອອກຈາກ Epic, ເພື່ອບໍ່ໃຫ້ໃຜສາມາດເຂົ້າສູ່ລະບົບ ID ຜູ້ຫຼິ້ນນັ້ນໄດ້ອີກ. Epic ເກັບສ່ວນທີ່ເຫຼືອຂອງບັນທຶກພາຍໃຕ້ ນະໂຍບາຍຄວາມເປັນສ່ວນຕົວຂອງ Epic Games. ການລຶບຂໍ້ມູນຂອງທ່ານທາງອີເມວບໍ່ປ່ຽນແປງບັນທຶກຂອງ Epic.

ຂໍ້ມູນໃນໂທລະສັບຂອງທ່ານ

ການລຶບໃນເກມຍັງເອົາໄຟລ໌ຮ້ານຄ້າອອກຈາກໂທລະສັບຂອງທ່ານ (ສຳເນົາກະເປົາເງິນຂອງທ່ານ, ການຊື້ທີ່ລໍຖ້າສົ່ງ, ຄຳຕອບຂອງທ່ານຕໍ່ຄຳຖາມເລື່ອງອາຍຸ ແລະ ຍອດລວມການໃຊ້ຈ່າຍຂອງເດືອນນີ້), ບັນທຶກການເຂົ້າສູ່ລະບົບ Google ຂອງທ່ານ ແລະ ID ອຸປະກອນ Epic. ການຕັ້ງຄ່າ ແລະ ເລເວວຂອງທ່ານຍັງຢູ່ໃນໂທລະສັບ. ພວກມັນບໍ່ເຄີຍຖືກສົ່ງໄປເຊີບເວີຂອງພວກເຮົາ.

ເພື່ອເອົາທຸກຢ່າງທີ່ເກມເກັບໄວ້ໃນໂທລະສັບຂອງທ່ານອອກ, ໃຫ້ລຶບບ່ອນເກັບຂໍ້ມູນຂອງແອັບໃນການຕັ້ງຄ່າ Android (ການຕັ້ງຄ່າ > ແອັບ > Battle Arena Worlds > ບ່ອນເກັບຂໍ້ມູນ > ລຶບບ່ອນເກັບຂໍ້ມູນ) ຫຼື ຖອນການຕິດຕັ້ງແອັບ. ການເຮັດແບບນີ້ຢ່າງດຽວ ບໍ່ໄດ້ລຶບກະເປົາເງິນໃນເຊີບເວີຂອງພວກເຮົາ. ແອັບນີ້ປິດການສຳຮອງຂໍ້ມູນ ແລະ ການໂອນຍ້າຍລະຫວ່າງອຸປະກອນຂອງ Android, ສະນັ້ນ Android ຈະບໍ່ເກັບສຳເນົາຂອງຂໍ້ມູນນີ້ໄວ້ໃນການສຳຮອງຂໍ້ມູນຂອງບັນຊີ Google ຂອງທ່ານ ແລະ ຈະບໍ່ຍ້າຍມັນໄປຍັງໂທລະສັບໃໝ່.

ເບິ່ງ ນະໂຍບາຍຄວາມເປັນສ່ວນຕົວຂອງ Battle Arena Worlds ສະບັບເຕັມ.

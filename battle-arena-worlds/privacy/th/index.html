นโยบายความเป็นส่วนตัวของ Battle Arena Worlds

นี่คือฉบับแปล หากมีความแตกต่างจากฉบับภาษาอังกฤษ ให้ถือฉบับภาษาอังกฤษเป็นหลัก

มีผลตั้งแต่วันที่ 25 ตุลาคม 2026

Battle Arena Worlds เป็นเกมแบทเทิลรอยัลแบบผู้เล่นหลายคนสำหรับ Android เผยแพร่โดย ST Projects ("เรา") นักพัฒนาอิสระที่ตั้งอยู่ในสหรัฐอเมริกา นโยบายนี้อธิบายว่าเกมเก็บข้อมูลอะไรบ้าง เพราะเหตุใด และข้อมูลนั้นจะเป็นอย่างไร นโยบายนี้ใช้กับแอป Android ที่เผยแพร่ภายใต้ชื่อแพ็กเกจ com.stprojects.battlearenaworlds

สรุปสั้น ๆ: คุณไม่จำเป็นต้องสมัครหรือเข้าสู่ระบบ หลังจากที่คุณยอมรับข้อกำหนดในการให้บริการ (ภาษาอังกฤษ) และนโยบายความเป็นส่วนตัวนี้แล้ว เกมจะลงชื่อเข้าใช้ Epic Online Services ให้คุณในเบื้องหลังด้วยบัญชีผู้เล่นแบบไม่ระบุตัวตนที่ผูกกับโทรศัพท์ของคุณ ไม่ได้ผูกกับชื่อหรืออีเมลของคุณ หากต้องการ คุณสามารถลงชื่อเข้าใช้ด้วย Google เพื่อให้บัญชียังอยู่หลังติดตั้งใหม่หรือเปลี่ยนโทรศัพท์ บัญชีนี้ใช้สำหรับแมตช์ออนไลน์และกระเป๋าเงินในร้านค้าของคุณ (เหรียญ เจม และไอเทมตกแต่งที่คุณเป็นเจ้าของ) ซึ่งเราเก็บไว้บนเซิร์ฟเวอร์ของเรา การซื้อทำผ่าน Google Play เกมไม่มีโฆษณา ไม่มีแชต ไม่มีเสียงสนทนา และไม่มีบริการวิเคราะห์หรือรายงานข้อขัดข้องของเราเอง และไม่สามารถเข้าถึงตำแหน่ง รายชื่อติดต่อ รูปภาพ กล้อง ไมโครโฟน หรือไฟล์ของคุณได้

บัญชีผู้เล่นของคุณ (Epic Online Services)

ฟีเจอร์ออนไลน์ใช้ Epic Online Services (EOS) ซึ่งให้บริการโดย Epic Games เกมจะไม่ขอบัญชี Epic อีเมล หรือรหัสผ่านจากคุณเลย แต่หลังจากที่คุณยอมรับข้อกำหนดในการให้บริการและนโยบายความเป็นส่วนตัวนี้แล้ว เกมจะลงชื่อเข้าใช้ด้วย ID อุปกรณ์แบบไม่ระบุตัวตน:

  • เมื่อลงชื่อเข้าใช้ครั้งแรก Epic SDK ในเกมจะสร้าง ID อุปกรณ์สำหรับการติดตั้งนี้และเก็บไว้ในพื้นที่จัดเก็บของแอปบนโทรศัพท์ของคุณ ขณะทำเช่นนั้น SDK จะส่งยี่ห้อและรุ่นของโทรศัพท์ของคุณไปยัง Epic ซึ่ง Epic ใช้เพื่อการวินิจฉัยปัญหา
  • จากนั้น Epic จะให้ ID ผู้เล่นแก่เกม (Epic เรียกว่า ProductUserId): รหัสสุ่ม 32 ตัวอักษรที่ระบุบัญชีของคุณในเกมนี้ ID นี้ไม่ได้เชื่อมโยงกับบัญชี Epic หรืออีเมลใด ๆ และจะเชื่อมโยงกับบัญชี Google ก็ต่อเมื่อคุณเลือกลงชื่อเข้าใช้ด้วย Google เท่านั้น (ดูด้านล่าง)
  • เกมจะสร้างชื่อผู้เล่นให้คุณ คือ "Player" ตามด้วยตัวเลขสุ่มสี่หลัก (เช่น Player4821) และส่งไปยัง Epic พร้อมการลงชื่อเข้าใช้ คุณเปลี่ยนชื่อนี้ไม่ได้ และชื่อนี้ไม่มีชื่อจริงของคุณเลย

Epic ประมวลผลข้อมูลนี้เพื่อให้บริการการลงชื่อเข้าใช้ การจับคู่แมตช์ และการเชื่อมต่อระหว่างผู้เล่น ภายใต้นโยบายความเป็นส่วนตัวของ Epic Games

การลงชื่อเข้าใช้ด้วย Google (ไม่บังคับ)

ในแท็บตั้งค่าของเกม คุณสามารถแตะ ลงชื่อเข้าใช้ด้วย Google ได้ ซึ่งเป็นตัวเลือกที่ไม่บังคับ: เกม แมตช์ออนไลน์ และร้านค้าทำงานได้ทั้งหมดโดยไม่ต้องใช้ จุดประสงค์เดียวคือเพื่อเก็บบัญชีผู้เล่นของคุณ และกระเป๋าเงินของคุณด้วย ไว้หากคุณติดตั้งเกมใหม่ ล้างข้อมูลเกม หรือย้ายไปใช้โทรศัพท์เครื่องใหม่

  • Android จะแสดงหน้าต่างลงชื่อเข้าใช้ของ Google ในครั้งแรก Google จะแจ้งคุณว่าจะแชร์ชื่อ อีเมล และรูปโปรไฟล์ของคุณกับแอป จากนั้น Google จะให้ โทเค็น Google ID ที่มีการลงนามแก่เกม
  • เกมจะส่งโทเค็นนั้นไปยัง Epic เท่านั้น Epic จะตรวจสอบและเชื่อมโยง ID ของบัญชี Google ของคุณเข้ากับ ID ผู้เล่นของคุณ เกมไม่อ่านหรือเก็บชื่อ อีเมล หรือรูปภาพของคุณ และเซิร์ฟเวอร์ของเราไม่เคยได้รับโทเค็นหรือรายละเอียดใด ๆ ของบัญชี Google ของคุณ
  • หลังติดตั้งใหม่หรือบนโทรศัพท์เครื่องใหม่ การลงชื่อเข้าใช้ด้วยบัญชี Google เดิมจะนำ ID ผู้เล่นและกระเป๋าเงินเดิมกลับมา หากโทรศัพท์มีความคืบหน้าภายใต้ ID ผู้เล่นอื่นอยู่แล้ว เกมจะถามว่าจะเก็บความคืบหน้าใดไว้ Epic จะลบ ID ผู้เล่นที่คุณไม่ได้เก็บไว้ ส่วนกระเป๋าเงินของ ID นั้นจะยังอยู่บนเซิร์ฟเวอร์ของเรา ซึ่งไม่มีใครลงชื่อเข้าใช้ได้ จนกว่าคุณจะขอให้เราลบ
  • เกมจะเก็บไฟล์ขนาดเล็กไว้บนโทรศัพท์ของคุณ เพื่อบันทึกว่าบัญชี Google ของคุณเชื่อมโยงกับ ID ผู้เล่นใด
  • ออกจากระบบ จะคงการเชื่อมโยงกับ Google ไว้ และทำให้โทรศัพท์กลับไปใช้บัญชีผู้เยี่ยมชมใหม่ที่ว่างเปล่า การลงชื่อเข้าใช้อีกครั้งจะนำบัญชีของคุณกลับมา

แท็บตั้งค่ายังแสดงรหัสผู้เล่นของคุณด้วย: 12 ตัวอักษรแรกของ ID ผู้เล่นของคุณ ซึ่งคุณสามารถคัดลอกและแจ้งเมื่อติดต่อเรา

แมตช์ออนไลน์

เมื่อคุณแตะเพื่อเล่นออนไลน์ เกมจะค้นหาห้อง (ล็อบบี้ EOS) ที่มีผู้เล่นได้สูงสุด 10 คน ระหว่างที่คุณอยู่ในห้อง เกมจะเผยแพร่รายละเอียดต่อไปนี้ให้เกมของผู้เล่นคนอื่นอ่านได้:

  • ID ผู้เล่นและชื่อผู้เล่นของคุณ และฮีโร่ที่คุณเลือก
  • รายละเอียดทางเทคนิคที่ใช้เลือกว่าโทรศัพท์ของผู้เล่นคนใดจะเป็นโฮสต์ของแมตช์: หน่วยความจำของโทรศัพท์ ระดับประสิทธิภาพกราฟิก ใช้ Wi-Fi หรืออินเทอร์เน็ตมือถือ เปิดโหมดประหยัดแบตเตอรี่หรือไม่ และค่าปิงของคุณไปยังผู้เล่นคนอื่น
  • เวอร์ชันของเกม และสถานะการเชื่อมต่อของคุณกับแมตช์

โทรศัพท์ของผู้เล่นคนหนึ่งจะเป็นโฮสต์ของแต่ละแมตช์ออนไลน์ และโทรศัพท์เครื่องอื่นจะเชื่อมต่อผ่านบริการแบบเพียร์ทูเพียร์ของ Epic เมื่อสามารถเชื่อมต่อโดยตรงได้ โทรศัพท์ในแมตช์จะแลกเปลี่ยนทราฟฟิกเครือข่ายกันโดยตรง แต่ละเครื่องจึงเห็นที่อยู่ IP ของเครื่องอื่นได้ มิฉะนั้นทราฟฟิกจะผ่านเซิร์ฟเวอร์รีเลย์ของ Epic ระหว่างแมตช์ เกมของโฮสต์จะได้รับการเคลื่อนไหวของคุณ ฮีโร่ของคุณ ไอเทมตกแต่งที่คุณสวมใส่ และผลแมตช์ของคุณ และส่งสำเนาสถานะของแมตช์ไปยังโทรศัพท์ของผู้เล่นคนอื่น เพื่อให้แมตช์ดำเนินต่อได้หากโฮสต์ออกไป ผู้เล่นคนอื่นจะเห็นชื่อผู้เล่นของคุณในฟีดการกำจัดและในผลการแข่งขัน

เกมไม่มีแชตข้อความและไม่มีแชตเสียง และไม่มีรายชื่อเพื่อน การเชิญ หรือสถานะออนไลน์

กระเป๋าเงินในร้านค้าของคุณ (เซิร์ฟเวอร์ของเรา)

ร้านค้าขายเฉพาะไอเทมตกแต่ง เพื่อป้องกันไม่ให้มีการแก้ไขยอดคงเหลือบนโทรศัพท์ กระเป๋าเงินของคุณจะเก็บไว้บนเซิร์ฟเวอร์ของเราและจัดเก็บภายใต้ ID ผู้เล่นของคุณ เมื่อคุณลงชื่อเข้าใช้ Epic แล้ว เกมจะส่งโทเค็นการลงชื่อเข้าใช้ที่ Epic ออกให้คุณไปยังเซิร์ฟเวอร์ของเรา ซึ่งพิสูจน์ ID ผู้เล่นของคุณ และเซิร์ฟเวอร์ของเราจะให้เซสชันแก่เกมซึ่งมีอายุ 30 วัน เซิร์ฟเวอร์ของเราจัดเก็บ:

ข้อมูลเหตุผล
ID ผู้เล่นของคุณเพื่อให้รู้ว่ากระเป๋าเงินใดเป็นของคุณ
เหรียญและเจมของคุณยอดคงเหลือของคุณ เพื่อไม่ให้แก้ไขได้บนโทรศัพท์
ไอเทมตกแต่งที่คุณเป็นเจ้าของและที่คุณสวมใส่อยู่เพื่อให้คุณเก็บไว้ได้ และเพื่อให้เกมคืนลุคของคุณจากเซิร์ฟเวอร์ของเราได้ (ผู้เล่นคนอื่นเห็นสิ่งที่คุณสวมใส่เพราะโทรศัพท์ของคุณส่งไอเทมที่สวมใส่ไปยังโฮสต์ของแมตช์ระหว่างแมตช์)
คุณซื้อแพ็กเริ่มต้นแล้วหรือไม่ กระเป๋าเงินของคุณสร้างเมื่อใด และเปลี่ยนแปลงครั้งล่าสุดเมื่อใดแพ็กเริ่มต้นขายเพียงครั้งเดียวต่อบัญชี ในช่วง 7 วันแรกของคุณ
เหรียญที่ได้รับวันนี้ และวันที่คุณได้รับโบนัสชนะครั้งแรกครั้งล่าสุดเพื่อใช้ขีดจำกัดเหรียญรายวันและโบนัสวันละครั้ง
เงินจริงที่ใช้ไปในเดือนปฏิทินนี้เพื่อใช้วงเงินใช้จ่ายรายเดือน (ดู "การซื้อ")
บันทึกของแมตช์และการซื้อที่เครดิตให้คุณแล้ว (ID แมตช์พร้อม ID ผู้เล่นของคุณ หรือแฮชทางเดียวของโทเค็นการซื้อ)เพื่อไม่ให้แมตช์หรือการซื้อเดียวกันถูกเครดิตซ้ำสองครั้ง
กระเป๋าเงินของคุณเวอร์ชันก่อนหน้าสูงสุด 2 เวอร์ชันข้อมูลสำรอง เพื่อให้กู้คืนกระเป๋าเงินของคุณได้หากเกิดปัญหา ระบบจะเก็บข้อมูลสำรองใหม่อย่างมากชั่วโมงละครั้ง และลบข้อมูลสำรองที่เก่ากว่าโดยอัตโนมัติ

เมื่อจบแต่ละแมตช์ เกมของโฮสต์ (หรือเกมของคุณเองในแมตช์เดี่ยว) จะรายงานไปยังเซิร์ฟเวอร์ของเราถึง ID ผู้เล่น อันดับ จำนวนการกำจัด และเวลาที่รอดชีวิตของผู้เล่นแต่ละคน พร้อม ID แมตช์ ความยาวของแมตช์ และวันที่ เซิร์ฟเวอร์ของเราจะคำนวณเหรียญจากรายงานนั้นโดยมีขีดจำกัดรายวัน และเพิ่มลงในกระเป๋าเงินของผู้เล่นแต่ละคน

เซิร์ฟเวอร์ของเราไม่เก็บชื่อผู้เล่น อีเมล รุ่นโทรศัพท์ หรือโทเค็นการลงชื่อเข้าใช้ Epic ของคุณ

การซื้อ (Google Play Billing)

เจมและแพ็กเริ่มต้นซื้อผ่าน Google Play Billing คุณชำระเงินให้ Google และข้อกำหนดการชำระเงินของ Google และนโยบายความเป็นส่วนตัวของ Google จะใช้กับการชำระเงิน เราไม่เคยเห็นหรือเก็บหมายเลขบัตร รายละเอียดธนาคาร ที่อยู่สำหรับการเรียกเก็บเงิน หรืออีเมลบัญชี Google ของคุณ เกมยังถาม Google Play ว่าบัญชี Play ของคุณอยู่ในประเทศใด คำตอบจะอยู่บนโทรศัพท์ของคุณและไม่ถูกส่งมาให้เรา

เมื่อคุณเริ่มการซื้อ เกมจะให้แฮชทางเดียว (MD5) ของ ID ผู้เล่นของคุณแก่ Google Play เป็นแท็กบัญชีของคำสั่งซื้อ ("obfuscated account ID" ของ Google) หลังจากคุณชำระเงิน เกมจะส่งสินค้าและโทเค็นการซื้อของ Google Play ไปยังเซิร์ฟเวอร์ของเรา เซิร์ฟเวอร์จะขอให้ Google Play ยืนยันว่าการซื้อเป็นของจริง ไม่เคยถูกใช้มาก่อน และไม่ได้ถูกคืนเงิน แล้วจึงเพิ่มเจมลงในกระเป๋าเงินของคุณ เราเก็บบันทึกของการซื้อแต่ละครั้งเพื่อยืนยันการซื้อ ป้องกันการฉ้อโกง จัดการการคืนเงิน และปฏิบัติตามภาระผูกพันด้านภาษีและกฎหมาย:

  • สินค้า หมายเลขคำสั่งซื้อ Google Play เวลาที่ซื้อ เป็นการซื้อทดสอบหรือไม่ และสถานะ (เช่น คืนเงินแล้ว พร้อมวันที่และเหตุผลที่ Google แจ้ง)
  • ID ผู้เล่นของคุณ และแท็กบัญชีที่ Google Play รายงานสำหรับคำสั่งซื้อ (แฮชของ ID ผู้เล่นของคุณ)

บันทึกจะจัดเก็บภายใต้แฮชทางเดียว (SHA-256) ของโทเค็นการซื้อ โดยไม่เก็บตัวโทเค็นไว้ Google ยังแจ้งเซิร์ฟเวอร์ของเราเมื่อมีการซื้อ คืนเงิน หรือยกเลิก และเซิร์ฟเวอร์ของเราจะขอรายการการซื้อที่คืนเงินแล้วจาก Google หลายครั้งต่อวัน เซิร์ฟเวอร์ของเราเก็บบันทึกของการแจ้งเตือนเหล่านั้นไว้ภายใต้แฮชเดียวกันและหมายเลขคำสั่งซื้อ

อายุและวงเงินใช้จ่าย การซื้อด้วยเงินจริงสำหรับผู้เล่นอายุ 18 ปีขึ้นไป ก่อนการซื้อด้วยเงินจริงครั้งแรก เกมจะถามว่าคุณอายุ 18 ปีขึ้นไปหรือไม่ หากคุณตอบว่าอายุต่ำกว่า 18 ปี การซื้อด้วยเงินจริงจะถูกปิดบนโทรศัพท์เครื่องนั้น (เหรียญยังใช้ได้) คำตอบของคุณจะเก็บไว้บนโทรศัพท์ของคุณเท่านั้น การซื้อด้วยเงินจริงยังจำกัดไว้ที่ US$200 ต่อเดือนปฏิทิน (UTC) ก่อนที่หน้าจอการซื้อของ Google Play จะเปิดขึ้น เกมจะตรวจสอบวงเงินบนโทรศัพท์ของคุณ และเซิร์ฟเวอร์ของเราจะตรวจสอบสำหรับบัญชีของคุณ โดยนับการซื้อแต่ละครั้งตามราคาขายในสหรัฐอเมริกา

ร้านค้าไม่มีกล่องสุ่มหรือไอเทมแบบจ่ายเงินสุ่ม

ข้อมูลที่จัดเก็บบนโทรศัพท์ของคุณ

เกมบันทึกข้อมูลต่อไปนี้ในพื้นที่จัดเก็บของแอปเองบนโทรศัพท์ของคุณ:

  • การตั้งค่า: ฮีโร่ที่คุณเลือก ความไวการควบคุม การยิงอัตโนมัติและแตะเพื่อสร้าง จำนวนบอท ระดับเสียง และคุณภาพกราฟิก รวมถึงระดับกราฟิกที่เกมเรียนรู้ว่าเหมาะกับโทรศัพท์ของคุณ
  • เลเวล คะแนนประสบการณ์ และอันดับกับจำนวนการกำจัดครั้งล่าสุดของคุณ
  • ชื่อผู้เล่นที่สร้างขึ้นของคุณ และ ID อุปกรณ์ Epic (เก็บโดย Epic SDK) หากคุณลงชื่อเข้าใช้ด้วย Google จะมีข้อมูลว่าบัญชี Google ของคุณเชื่อมโยงกับ ID ผู้เล่นใด
  • สำเนากระเป๋าเงินของคุณตามที่เซิร์ฟเวอร์ของเราส่งมาล่าสุด เพื่อให้ร้านค้าทำงานแบบออฟไลน์ได้ ผลแมตช์และการซื้อที่รอส่งไปยังเซิร์ฟเวอร์ของเรา คำตอบของคุณต่อคำถามเรื่องอายุ และยอดใช้จ่ายของเดือนนี้
  • ID สุ่มสำหรับการติดตั้งนี้ ซึ่งใช้โดยร้านค้าบนโทรศัพท์เท่านั้นก่อนที่การลงชื่อเข้าใช้ Epic จะเสร็จสมบูรณ์ และจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของเราเลย
  • การยอมรับข้อกำหนดในการให้บริการและนโยบายความเป็นส่วนตัวนี้ของคุณ: วันที่มีผลบังคับใช้ของฉบับที่คุณยอมรับ และเวลาที่คุณยอมรับ ข้อมูลนี้จะอยู่บนโทรศัพท์ของคุณเท่านั้น และจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของเราเลย
  • ระหว่างที่คุณอยู่ในแมตช์ออนไลน์ จะมีบันทึกสั้น ๆ เกี่ยวกับห้องและแมตช์ (เพื่อให้เกมกลับเข้าร่วมได้หากเกมปิดไป) บันทึกนี้จะถูกลบเมื่อแมตช์จบ
  • ไฟล์ประสิทธิภาพขนาดเล็กหนึ่งไฟล์ต่อเซสชัน (อัตราเฟรมและการตั้งค่ากราฟิกของเกม) ซึ่งเก็บไว้บนโทรศัพท์ของคุณและไม่ถูกอัปโหลด

แอปปิดการสำรองข้อมูลและการย้ายข้อมูลระหว่างอุปกรณ์ของ Android ดังนั้น Android จะไม่คัดลอกข้อมูลนี้ไปยังข้อมูลสำรองในบัญชี Google ของคุณหรือไปยังโทรศัพท์เครื่องใหม่ กระเป๋าเงินของคุณเก็บไว้บนเซิร์ฟเวอร์ของเรา หากต้องการเก็บไว้เมื่อย้ายไปใช้โทรศัพท์เครื่องใหม่ ให้ลงชื่อเข้าใช้ด้วย Google ก่อน

สิทธิ์

เกมจะไม่ขอสิทธิ์ใด ๆ จากคุณเลย ไฟล์ Manifest ของ Android ของเกมประกาศเฉพาะสิทธิ์ที่ Android ให้โดยไม่ต้องถาม:

  • การเข้าถึงอินเทอร์เน็ต และการดูสถานะเครือข่ายและ Wi-Fi (สำหรับการเล่นออนไลน์ และเพื่อรู้ว่าคุณใช้ Wi-Fi หรืออินเทอร์เน็ตมือถือ)
  • Google Play Billing และการตรวจสอบใบอนุญาตของ Google Play
  • การสั่น การทำให้โทรศัพท์ไม่เข้าสู่โหมดพัก และการเปลี่ยนการตั้งค่าเสียง (ใช้โดยเอนจินเกม)
  • บริการที่ทำงานอยู่เบื้องหน้า (การซิงค์ข้อมูล) และการเริ่มทำงานหลังรีสตาร์ทโทรศัพท์: ใช้โดยไลบรารีที่ดาวน์โหลดและตั้งค่าข้อมูลของเกมจาก Google Play และโดยไลบรารีงานเบื้องหลังของ Android
  • สิทธิ์เฉพาะของแอปหนึ่งรายการ ซึ่งมีเพียงตัวแอปเท่านั้นที่ถือ ใช้โดยไลบรารี Android ภายในแอป

เกมไม่ขอสิทธิ์เข้าถึงตำแหน่ง รายชื่อติดต่อ กล้อง ไมโครโฟน รูปภาพ หรือพื้นที่จัดเก็บ และไม่สามารถเข้าถึงสิ่งเหล่านั้นได้ การลงชื่อเข้าใช้ด้วย Google ที่ไม่บังคับใช้ Credential Manager ของ Android และไลบรารีการลงชื่อเข้าใช้ของ Google และทำงานเฉพาะเมื่อคุณแตะ ลงชื่อเข้าใช้ด้วย Google (หรือเมื่อคุณลงชื่อเข้าใช้แล้ว เพื่อตรวจสอบการเชื่อมโยงเมื่อจำเป็น) แพ็กเกจแอปยังมีไลบรารีบริการ Google Play ที่เอนจินเกมเพิ่มไว้ตามค่าเริ่มต้น ได้แก่ ไลบรารี Google Sign-In รุ่นเก่าและ Play Games Services (ซึ่งเริ่มต้นตัวเองเมื่อแอปเริ่มทำงาน เราไม่ได้ตั้งค่าเกม Play Games ไว้ จึงไม่มีการลงชื่อเข้าใช้หรือสร้างโปรไฟล์ Play Games) และไลบรารีตำแหน่ง Drive และ FIDO ที่ไม่มีส่วนใดในเกมเรียกใช้ หากไม่มีสิทธิ์ที่เกี่ยวข้อง ไลบรารีตำแหน่งจะไม่สามารถเข้าถึงตำแหน่งของคุณได้

โฆษณา การวิเคราะห์ และรายงานข้อขัดข้อง

Battle Arena Worlds ไม่แสดงโฆษณา และไม่มี SDK โฆษณา ไม่มีบริการวิเคราะห์หรือรายงานข้อขัดข้องของเราเอง และไม่ติดตามคุณข้ามแอปหรือเว็บไซต์อื่น

ข้อมูลที่แชร์กับบุคคลที่สาม

Epic Games (Epic Online Services) ให้บริการการลงชื่อเข้าใช้แบบไม่ระบุตัวตน ห้อง และการเชื่อมต่อระหว่างผู้เล่น และได้รับข้อมูลที่อธิบายไว้ใน "บัญชีผู้เล่นของคุณ" และ "แมตช์ออนไลน์" หากคุณลงชื่อเข้าใช้ด้วย Google Epic จะได้รับโทเค็น Google ID ของคุณด้วย และเก็บการเชื่อมโยงระหว่างบัญชี Google ของคุณกับ ID ผู้เล่นของคุณ นโยบายความเป็นส่วนตัวของ Epic Games

Google ให้บริการการลงชื่อเข้าใช้ด้วย Google ที่ไม่บังคับ ดังนั้นหากคุณใช้ Google จะรู้ว่าคุณลงชื่อเข้าใช้ Battle Arena Worlds Google Play จัดการการชำระเงินและได้รับแท็กบัญชีที่แฮชแล้วในคำสั่งซื้อของคุณ เซิร์ฟเวอร์ของเราติดต่อ Google Play เพื่อยืนยันการซื้อ นโยบายความเป็นส่วนตัวของ Google

Google Cloud โฮสต์เซิร์ฟเวอร์และฐานข้อมูลของเรา Google ประมวลผลข้อมูลนี้ในนามของเรา ประกาศความเป็นส่วนตัวของ Google Cloud

ผู้เล่นคนอื่นในแมตช์ออนไลน์ของคุณจะเห็นชื่อผู้เล่น ฮีโร่ และไอเทมตกแต่งที่คุณสวมใส่ และโทรศัพท์ของพวกเขาจะได้รับรายละเอียดแมตช์ที่อธิบายไว้ใน "แมตช์ออนไลน์"

เราไม่ขายข้อมูลของคุณ และไม่แชร์ข้อมูลกับผู้อื่น เว้นแต่กฎหมายกำหนด

สถานที่จัดเก็บข้อมูลของคุณ

เซิร์ฟเวอร์ของเราทำงานบน Google Cloud ใน us-central1 (สหรัฐอเมริกา) เกมให้บริการผ่าน Google Play ในหลายประเทศ ไม่ว่าคุณจะใช้งานที่ใด ข้อมูลที่อธิบายไว้ใน "กระเป๋าเงินในร้านค้าของคุณ" และ "การซื้อ" จะถูกส่งไปยังเซิร์ฟเวอร์ของเราในสหรัฐอเมริกา ซึ่งกฎหมายคุ้มครองข้อมูลอาจแตกต่างจากที่ที่คุณอยู่ Epic ประมวลผลข้อมูลที่ได้รับตามที่อธิบายไว้ในนโยบายความเป็นส่วนตัวของ Epic

วิธีปกป้องข้อมูลของคุณ

การสื่อสารทั้งหมดระหว่างแอปและเซิร์ฟเวอร์ของเราได้รับการเข้ารหัสระหว่างการรับส่ง (HTTPS) เซิร์ฟเวอร์ของเราจะเปิดเซสชันสำหรับ ID ผู้เล่นด้วยโทเค็นการลงชื่อเข้าใช้ที่ลงนามโดย Epic เท่านั้น และเซสชันจะผูกกับแอปนี้และ ID ผู้เล่นของคุณ และหมดอายุหลัง 30 วัน เซิร์ฟเวอร์จำกัดจำนวนคำขอที่รับ เพื่อป้องกันการใช้งานในทางที่ผิด

บันทึกของเซิร์ฟเวอร์ของเราบันทึกเวลา ประเภทคำขอและผลลัพธ์ ระยะเวลาที่ใช้ และที่อยู่ IP ที่ส่งคำขอมา บันทึกคำขอของ Google Cloud ยังบันทึกที่อยู่คำขอแบบเต็มและ User Agent ของอุปกรณ์ของคุณ (ซึ่งอาจรวมถึงเวอร์ชันของแอปและ Android) บางบรรทัดของบันทึกมี 12 ตัวอักษรแรกของ ID ผู้เล่นของคุณ สินค้า หมายเลขคำสั่งซื้อ Google Play ไอเทมที่คุณซื้อด้วยเหรียญหรือเจม เหรียญที่เครดิตหลังแมตช์ หรือ 12 ตัวอักษรแรกของแฮชของโทเค็นการซื้อ บันทึกไม่เคยมี ID ผู้เล่นแบบเต็ม โทเค็นการลงชื่อเข้าใช้หรือโทเค็นเซสชัน หรือโทเค็นการซื้อของคุณ เราใช้บันทึกเหล่านี้เพื่อความปลอดภัย เพื่อจำกัดการใช้งานในทางที่ผิด และเพื่อแก้ไขปัญหา Google Cloud เก็บบันทึกไว้ประมาณ 30 วันตามค่าเริ่มต้น

ประวัติการซื้อ (สินค้า หมายเลขคำสั่งซื้อ เวลา สถานะ)เก็บรวบรวม ไม่แชร์ไม่บังคับ: เฉพาะเมื่อคุณซื้อฟังก์ชันการทำงานของแอป, การป้องกันการฉ้อโกง ความปลอดภัย และการปฏิบัติตามข้อกำหนด
กิจกรรมในแอป: การดำเนินการอื่นๆ (ผลแมตช์ เหรียญ ไอเทมตกแต่งที่เป็นเจ้าของและที่สวมใส่)เก็บรวบรวม ไม่แชร์จำเป็นฟังก์ชันการทำงานของแอป, การป้องกันการฉ้อโกง ความปลอดภัย และการปฏิบัติตามข้อกำหนด
ข้อมูลและประสิทธิภาพของแอป: ข้อมูลประสิทธิภาพอื่นๆ (หน่วยความจำโทรศัพท์ ระดับประสิทธิภาพ ประเภทเครือข่าย โหมดประหยัดแบตเตอรี่ ปิง รุ่นโทรศัพท์)เก็บรวบรวม (โดย Epic สำหรับการจับคู่แมตช์และการลงชื่อเข้าใช้) ไม่แชร์จำเป็นฟังก์ชันการทำงานของแอป

ข้อมูลทั้งหมดนี้ได้รับการเข้ารหัสระหว่างการรับส่ง คุณสามารถลบข้อมูลของคุณในเกม (ตั้งค่า > ลบข้อมูลของฉัน) หรือขอให้เราลบทางอีเมล ตามที่อธิบายไว้ใน "การลบข้อมูลของคุณ" หลังจากนั้นบันทึกการซื้อจะเก็บไว้จนถึง 7 ปีหลังการซื้อแต่ละครั้ง โดยไม่มี ID ผู้เล่นของคุณ
